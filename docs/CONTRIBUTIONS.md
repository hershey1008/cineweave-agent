# 实现范围与来源

本项目是在 Datawhale FunRec 推荐链路基础上的工程扩展，避免将教程复现、已有模型与新增实现混为一谈。

| 来源 | 模块 |
| --- | --- |
| 复用并适配 FunRec | 原业务 API、认证、浏览页、离线特征与训练、YouTubeDNN / I2I / 类型偏好召回、DeepFM、原冷启动能力、模型定义 |
| CineWeave 新增 | 结构化意图协议、LLM 适配、会话状态机、拥有者校验、幂等与 CAS、语义内容清洗和索引、BGE-M3 独立服务、融合与会话排序、事实解释、多轮聊天页面、反馈事件、回归测试与展示材料 |
| CineWeave 修正 | 序列时间方向、年份特征、ES 字段匹配、降级信号、电影实体类型隔离、跨层超时预算与接口错误分类 |

本地演示复用已有 YouTubeDNN/DeepFM 产物，没有在本次任务中重新训练出新的推荐模型。96 项单元测试与五轮真实 LLM 回归证明的是实现和功能路径；不能据此宣称 nDCG、CTR、用户留存或在线业务收益提升。

当前是“LLM 意图解析与工具编排 + 语义检索 + 传统推荐排序”。推荐理由使用事实模板；不是 Semantic ID 自回归生成式召回，也不是完全自主决策的通用 Agent。

若用于简历，可使用如下描述，并按自己实际掌握和完成的工作调整：

> 基于 FunRec 扩展多轮电影选片应用，将 LLM 结构化意图解析、BGE-M3 语义召回与 YouTubeDNN/DeepFM 推荐链路集成；实现会话条件更新、硬过滤、指代替换、幂等与并发版本控制，以及事实解释和故障降级。

更详细的新增、修改、复用目录见 [项目结构](agent-v1/project-structure.md)，测试口径见 [验收记录](LOCAL_VALIDATION.md)。
